# KNN

ตัวอย่างการทำงานของ **K-Nearest Neighbors (KNN)** แบบทีละขั้น เขียนด้วย Python + NumPy
ทายว่าจุด **X** ที่ (0, 0) เป็นสีอะไร จากจุดตัวอย่าง 9 จุด (Red / Green / Blue) โดยลอง k = 1, 3 และ 6

## วิธีรัน

```bash
pip install -r requirements.txt
python knn.py
```

## ข้อมูล

| จุด | พิกัด (x, y) | สี | ระยะจาก X |
|:-:|:-:|:-:|:-:|
| 7 | (1, −1) | Red | 1.41 |
| 4 | (2, 1) | Green | 2.24 |
| 6 | (2.5, 0) | Green | 2.50 |
| 1 | (−3, 1) | Blue | 3.16 |
| 2 | (−2, 2.5) | Blue | 3.20 |
| 9 | (2, −3) | Red | 3.61 |
| 3 | (−1, 4) | Blue | 4.12 |
| 8 | (−3, −3) | Red | 4.24 |
| 5 | (4, 3) | Green | 5.00 |

## ขั้นตอนของ KNN (`knn_predict`)

1. คำนวณระยะ Euclidean จาก X ไปทุกจุด ด้วย `np.linalg.norm`
2. เรียงจากใกล้ไปไกล
3. เลือก k จุดที่ใกล้ที่สุด
4. นับเสียงส่วนมาก (majority vote) ว่าสีไหนมากที่สุด
5. ถ้าคะแนนเสมอ ตัดสินด้วย **Weight by distance**: แต่ละจุดได้คะแนน 1 / ระยะ แล้วรวมตามสี (จุดที่ใกล้กว่ามีเสียงมากกว่า)

## ผลลัพธ์

| k | เพื่อนบ้าน | นับเสียง | ผล |
|:-:|---|---|:-:|
| 1 | 7 | Red 1 | **Red** |
| 3 | 7, 4, 6 | Green 2, Red 1 | **Green** |
| 6 | 7, 4, 6, 1, 2, 9 | Red 2, Green 2, Blue 2 (เสมอ) | **Red** (ตัดสินด้วยน้ำหนักระยะ) |

คะแนนถ่วงน้ำหนักตอน k = 6: Red 0.984 (1/1.41 + 1/3.61), Green 0.847, Blue 0.629

**ข้อสังเกต:** ค่า k ที่ต่างกันให้คำตอบต่างกัน k เล็กเชื่อจุดที่ใกล้ที่สุดมาก (ไวต่อ noise)
ส่วน k ใหญ่ดึงจุดที่ไกลเข้ามาโหวตด้วย จนอาจเสมอกันได้ จึงมักเลือก k เป็นเลขคี่ หรือใช้การถ่วงน้ำหนักด้วยระยะ

## ลองแก้เอง

- เปลี่ยนตำแหน่งจุดที่ต้องการทาย: `X_target = np.array([x, y])`
- เพิ่มหรือแก้จุดใน `dataset` รูปแบบ `('หมายเลข', np.array([x, y]), 'สี')`
- ลองค่า k อื่น: แก้ `(1, 3, 6)` ในบรรทัดสุดท้ายของ `knn.py`
